# Sicumi — правила для AI-агентов

Полная спецификация: `docs/SPEC.md`. Прочитай её перед крупными изменениями.

## Продукт
- Приложение **только на иврите**. Других языков интерфейса нет и не будет.
- Два модуля: протоколы встреч (запись/импорт аудио → STT → LLM → протокол) и голосовая диктовка
  (iOS — клавиатура; Android — плавающая кнопка через AccessibilityService, своей клавиатуры НЕТ).
- BYOK: пользователь вставляет свой API-ключ. Провайдеры STT: Gemini, Soniox, OpenAI, Groq, свой endpoint.
- Бесплатно. Сервер (Supabase) — только для аккаунта и синхронизации текстов. Ключи и аудио на сервер не уходят.
- Порядок: сначала Android до релиза, потом iOS.

## RTL — обязательные правила
- Все строки интерфейса — в `res/values/strings.xml` на иврите. Никаких захардкоженных строк в UI-коде
  (исключение: временный `DemoData.kt`).
- RTL задаётся принудительно в `SicumiTheme` (`LocalLayoutDirection provides Rtl`). Любое новое окно
  (оверлей кнопки диктовки, диалоги вне основного дерева) тоже оборачивать в `SicumiTheme`.
- Только `start`/`end`, никогда `left`/`right`. Для `offset` и выравниваний помнить, что в RTL End = левый край.
- Зеркалить: стрелки назад/вперёд, шевроны. НЕ зеркалить: воспроизведение и прогресс аудио, волну записи,
  микрофон, галочку, цифры, логотипы.
- Латиница, телефоны, email, ссылки внутри иврита — оборачивать в Unicode-изоляты (U+2068 … U+2069).
- Дата `dd/MM/yyyy`, время 24 ч, цифры 0–9.
- Обращение к пользователю без рода: инфинитив на кнопках («להקליט», «לשתף»).

## Дизайн
- Направление C «Смелые формы». Токены: `shared/design/tokens.json`, в коде — `ui/theme/*`.
- Шрифты: Secular One (заголовки), Heebo (текст) — лежат в `res/font`.
- Форма «капля» (`SicumiShapes.Blob`) — только у главного действия.
- Касание ≥ 44dp, контраст текста ≥ 4.5:1.
- Макеты: холст «Sicumi — макеты Android» в Claude: https://claude.ai/artifact/FxyQ3DyFJnk7vardrKy3ob (приватный, доступ у Kosta).

## Стек Android
- Kotlin, Jetpack Compose (Material 3), AGP 9 со встроенным Kotlin (плагин `kotlin-android` не нужен).
- minSdk 26, compile/target 37, пакет `app.sicumi`.
- Модули по спецификации: `:app`, `:core`, `:overlay` — пока есть только `:app`, остальные добавляются по мере работы.

## Безопасность
- Папка `documents/` в git не попадает (там реальные протоколы). Не коммитить ключи, `.env`, keystore.

## Git
- Коммиты и PR — без строк `Co-Authored-By`, `Claude-Session` и любой другой атрибуции AI. Автор — только Kosta.
